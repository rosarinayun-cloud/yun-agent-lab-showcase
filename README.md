# Yun Agent Lab

公开研究档案 · v0.1.1 · 首次公开：2026-10-27

Yun Agent Lab 是于 **2026 年 10 月启动**的个人 Agent 系统工程探索。研究关注现有模型、工具与运行环境如何形成可检验的工作闭环：检索资料、调用工具、对照视频画面、验证产物，以及在失败后保存状态并恢复。启动月份来自内部实验与工程记录的交叉核对，不代表当时已经公开发表，也不主张技术原创优先权。

项目围绕模型与工具协作、研究任务执行及工程反馈开展实验，复用现有模型和成熟工具，不训练基础模型。

## 已有实验支持的进展

| 方向 | 观察结果 | 验证范围 |
|---|---|---|
| 外部模型与工具链 | DeepSeek 驱动 Codex，完成真实 MCP 工具调用；批准规则与服务端记录可对应 | 固定工具和具体实验，不代表任意工具都安全可靠 |
| 浏览器交互 | 模型完成隔离测试页读取与模拟提交；后续取得真实 Bilibili 页面资料 | 模拟提交不等于真实平台发言 |
| 自主资料研究 | 一轮研究由模型自行检索、选择六个视频并追加取证；31 次工具调用可与服务端审计对齐 | 含字幕、评论与楼中楼样本；不证明视频作者的技术主张已复现 |
| 按需视觉研究 | 模型自主选取视频时窗，实际 JPEG 进入视觉请求，并依据缺口追加关键帧 | 离散帧研究；小字、代码和动态因果仍需核验 |
| 失败与恢复 | 保留审批阻断、启动器挂起、传输失败和识读误差；后续改动分别验收 | 不把退出码 0 当作业务成功 |
| VPS 调度 | 原生定时触发、等待任务不阻塞独立任务、三类有界恢复场景有实验记录 | 实验域通过；不代表任意工程任务或生产系统长期自治 |

## 当前能力边界

- 视频首稿存在数值识读、界面归属与证据外推错误，需核验后交付。模型主动补帧与后续审阅应分别记账。
- 浏览器研究使用过用户授权的登录态；专用 Agent 账号、真实社交互动、第二平台闭环尚未验收，不公开账号身份。
- VPS 受信管理账户的广泛管理员权限，以及一次临时 systemd 服务的创建、启动、停止和撤销验收已 VERIFIED；生产 Controller 自主利用这些管理权限尚未完成验收。Default-Allow 整体仍为 PARTIAL，不代表生产系统已完成全面自治。
- Token 用量可来自运行记录；货币成本如无账单只能是估算。本档案不承诺固定费用、零误差或全天候可用。
- 不主张 AGI、ASI、完全自主递归进化或基础模型自我改进。当前研究对象是工具编排、工程反馈与有边界的系统迭代。
