# Yun Agent Lab

公开研究档案 · Autonomous Operation v0.1 里程碑更新 · 首次公开：2026-10-27

Yun Agent Lab 是于 **2026 年 10 月启动**的个人 Agent 系统工程探索。研究关注现有模型、工具与运行环境如何形成可检验的工作闭环：检索资料、调用工具、对照视频画面、验证产物，以及在失败后保存状态并恢复。启动月份来自内部实验与工程记录的交叉核对，不代表当时已经公开发表，也不主张技术原创优先权。

项目围绕模型与工具协作、研究任务执行及工程反馈开展实验，复用现有模型和成熟工具，不训练基础模型。

- **自主研发与成果交付**：已产出经过独立业务检查的私有软件候选，并保存版本与交付证据。候选完成不等于已推广到生产。
- **Delivery Pipeline 恢复**：17项历史交付阻断及1项新增阻断，经过一次有界工程修复和逐项重新验收后恢复；冻结原件保持不变。随后 Turn 173 的新成果由自主循环正常交付，未靠重跑旧模型成果补齐。

交付修复本身不作为“Agent 已能自主修复整个系统”的证据。Turn 173 是执行序号，不表示173项成功成果。持续运行样本不等于长期零维护、所有故障自动恢复或无限期无人监管。详细范围与失败记录见 [里程碑](MILESTONES.md#autonomous-operation-v01--持续自主运行与交付恢复)。

## 当前能力边界

- 视频首稿存在数值识读、界面归属与证据外推错误，需核验后交付。模型主动补帧与后续审阅应分别记账。
- 浏览器研究使用过用户授权的登录态；专用 Agent 账号、真实社交互动、第二平台闭环尚未验收，不公开账号身份。
- VPS 已有真实模型驱动工程、连续自主研发和限定交付闭环的生产证据；早期“生产 Controller 尚未验收”是当时的历史状态。广泛主机自治仍有未验证范围，本里程碑不证明通用系统维修、长期零维护或全面自治。
- Token 用量可来自运行记录；货币成本如无账单只能是估算。本档案不承诺固定费用、零误差或全天候可用。
- 不主张 AGI、ASI、完全自主递归进化或基础模型自我改进。当前研究对象是工具编排、工程反馈与有边界的系统迭代。
